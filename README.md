## 🚀 Key Features

- **Modern & Responsive UI:** Fully optimized for mobile, tablet, and desktop devices.
- **High Performance:** 
  - Optimized gallery carousel with zero layout thrashing.
  - Efficient asset management (lazy loading, compressed images).
- **Security First:**
  - Integrated Honeypot field for anti-spam form protection.
  - Secure integration with EmailJS for serverless contact form handling.
- **Accessibility (A11y):**
  - Custom accessibility menu for high contrast, readable fonts, and animation control.
  - WCAG-compliant semantic structure.
- **SEO Optimized:**
  - Perfect 100/100 target SEO score.
  - Full Open Graph (OG) and Twitter metadata.
  - Automated Sitemap and Robots.txt generation.
- **Visual Effects:** 
  - Interactive Particles.js background.
  - Smooth Lenis scroll integration.
  - Custom SVG animations (dome and bullet camera graphics).

## 🛠️ Technology Stack

- **Frontend:** HTML5, Vanilla CSS3, JavaScript (ES6+).
- **Libraries:**

  - [Lenis](https://lenis.darkroom.engineering/) - Smooth scrolling.
  - [FontAwesome](https://fontawesome.com/) - Icons.
- **Deployment:** GitHub Pages.

## 📦 Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/ofirsecuritysolutions.git
   cd ofirsecuritysolutions
   ```

2. **Configuration:**
   The contact form uses EmailJS. To use your own service, update the following keys in `index.html` and `script.js`:
   - `service_id`
   - `template_id`
   - `public_key`

3. **Running locally:**
   Simply open `index.html` in any modern browser, or use a local server like VS Code Live Server.
